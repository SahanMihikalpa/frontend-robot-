# Frontend Docs

This folder contains the frontend-facing documentation for `frontend-robot`.

## Documents

- [API Binding Plan](API_BINDING_PLAN.md) - maps backend API groups to frontend pages, components, and implementation status.
- [Frontend Implementation Tracker](IMPLEMENTATION_TRACKER.md) - living checklist for frontend work and doc maintenance.

## Maintenance Rules

- Update the API binding plan whenever a backend endpoint is wired in the frontend.
- Update the implementation tracker whenever a frontend page or shared component changes.
- Keep setup instructions and environment variables aligned with the actual app configuration.

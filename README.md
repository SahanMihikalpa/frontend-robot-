# frontend-robot

Next.js frontend for the Personalized Robot project.

## Quick Start

1. Install dependencies:

```bash
npm install
```

2. Copy environment example and edit if needed:

```bash
Copy-Item .env.local.example .env.local
```

3. Run the dev server:

```bash
npm run dev
```

The frontend expects the backend API at `NEXT_PUBLIC_API_BASE_URL` (default: `http://localhost:8000`).
